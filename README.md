# Taha Momayiz — engineering portfolio

A static portfolio featuring robotics research, UAV senior design, industrial computer vision, and visual tool tracking.

## Preview

Run a static web server from this directory, for example:

```sh
python -m http.server 8765
```

Open `http://localhost:8765`. No application dependencies or build step are required.

## Hosting

The site is designed for GitHub Pages at `https://yumtaha.github.io/`, published from the root of the `main` branch. `.nojekyll` preserves the static files as supplied.

## Content updates

Keep project status, personal contributions, image captions, and publication status accurate. The UAV project is ongoing; the carbide-tip inspection manuscript is under review. Update images only with permission, and retain team and publication credit.

Project source code linked from the portfolio has its own repository and licensing terms. Portfolio images and research materials are not granted a reuse license by this repository.
